# GymFlow 1.0.7

- Added a Remaining payment filter for memberships with outstanding balances. Pending now filters the receipt status separately.
- Payment entry and installment scheduling no longer require the Super Admin password. Payment edits and deletion remain protected.
- Revenue and expense creation, editing and deletion no longer require the Super Admin password.
- Member creation, editing and deletion, and member subscription creation, editing, cancellation and deletion no longer require the Super Admin password.
- Improved shared table pagination text and spacing in Arabic and English.
- Revenue forms open maximized.
- Added Eng. Tamer Ahmed and 01552222716 beneath the Gym Flow branding.
- Includes the current database recovery, responsive layout and bundled runtime improvements.

Windows installers include their Java runtime (EXE and MSI). Linux is supplied as a DEB with a bundled runtime. Customer databases and credentials are excluded from packages.

Back up the existing database before upgrading. Install the matching platform package and retain the existing application data directory.
